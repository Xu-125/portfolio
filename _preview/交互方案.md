# 参考页面的交互机制拆解 → 映射到你的作品集

## 它到底做对了什么

这个页面**没有炫技动效**（我扫过全页，只有 0.15s 颜色过渡）。它"有趣、可读性强、突出重点、交互方便"靠的是**信息架构的交互设计**，不是动画。

核心一句话：**左边讲故事，右边给细节，两边独立滚动，操作按钮平时藏起来。**

---

## 六条可复用机制

### 1. 双栏独立滚动（最核心）

它的实现：
```
main { position: fixed; inset: 0; top: 80px; display: flex }
  左栏 { width: 50%; overflow-y: auto }   ← 叙述内容
  右栏 { flex: 1; overflow-y: auto; border-left: 1px }  ← 技术细节
```

页面本身**不滚动**（bodyH = 960 = 视口高度），两栏各自滚。

**好处**：看左边的介绍时，右边的参数一直在视野里，不用来回翻。

**用到你的页面**：
作品区左栏放大图 + 说明，右栏放数据明细 + 链接。你现在是一张卡里塞全部信息，卡片就必须做小、字就必须挤。拆成双栏后，图能放大，数据能展开。

---

### 2. 右栏顶部 Tab 切换同一对象的不同视角

它有 5 个 tab：`Preview | DESIGN.md | Tailwind v4 | CSS Variables | Design Tokens`

同一套设计系统，5 种呈现方式，左栏内容始终不变。

**用到你的页面**：
作品右栏可以做 3 个 tab：`成果数据 | 我做了什么 | 原文链接`

这样每屏的信息量可控，但深度信息一个点击就到。

---

### 3. 操作按钮 hover 才浮现

色卡的 Copy 按钮实现：
```css
opacity: 0;
transition: opacity;
/* 父元素 hover 时 */
group-hover:opacity-100
```

平时只看到纯色块，鼠标移上去才出现「Copy」。

**用到你的页面**：
作品卡平时只显示封面 + 标题 + 一个大数字，hover 时才浮现「打开作品 ↗」。界面立刻清爽，但操作依然一步可达。

---

### 4. 渐进展开（Show all N steps）

间距刻度平时只显示常用的几档，底部一个「Show all 10 steps」，点开看全部。

**用到你的页面**：
实习经历每条平时显示 1 个核心数字，点击展开显示全部 3-4 个指标。首屏信息密度降下来，想看细节的人点一下就有。

---

### 5. 面包屑常驻顶栏

`R / Styles / Superr` 一直在顶部，永远知道自己在哪。

**用到你的页面**：
你现在的顶栏是 `Profile / Work / Contact` 三个平级按钮。可以改成显示当前位置的面包屑，比如在作品区时显示 `作品 / 豆包工作 0→1`。

---

### 6. 每个数据都可复制

所有色值、token 都能一键复制。这是"为用户的下一步动作着想"。

**用到你的页面**：
邮箱和微信号做成点击即复制，而不是让人手动选中。这是招聘方真正会用的动作。

---

## 落到你的页面：具体改法

### 作品屏改双栏

```
┌─────────────────────┬──────────────────────┐
│                     │ 数据 | 做了什么 | 链接 │ ← tab
│   封面大图           ├──────────────────────┤
│   （可点击跳转）      │ 1000w+  视频全网观看   │
│                     │ 55w+    推文阅读       │
│   豆包工作 0→1       │ 2w/3w   首周涨粉       │
│   冷启动与官宣        │ 5×4     竞品研究       │
│                     │                      │
│   ← 上一个  下一个 →  │ [打开原文 ↗]          │
└─────────────────────┴──────────────────────┘
     左栏：视觉主体          右栏：可切换的细节
```

左栏用你现在的弧形卡片滑动（保留），右栏跟着当前卡片更新数据。

### 实习屏改「时间轴 + 详情栏」

```
┌────────────────────────────────────────────┐
│  ●─────●─────●─────●─────●                 │ ← 时间轴（可拖）
│  飞书   小红书  海尔   中国日报  人民网         │
├────────────────────────────────────────────┤
│  字节跳动 · 飞书 Lark                        │
│  产品 PR & 增长策略运营                       │
│                                            │
│  0→1        -60%        5×4                │ ← 点节点切换
│  AI产品冷启动  Agent提效   竞品研究            │
└────────────────────────────────────────────┘
```

轴在上面，点哪个节点下面就换内容。比现在 5 张卡平铺更清楚，也更省空间。

## 关于「有趣」

参考页面的趣味来自**探索感**——每处都有可点、可切、可复制的东西，鼠标移过去会有反应。不是动画好看，是"这个页面在回应我"。

你的页面可以加的克制反馈：
- 数字 hover 时轻微放大（`scale(1.04)`，200ms）
- 卡片 hover 时封面缓慢放大（你已有）
- 时间轴节点 hover 时圆点扩大 + 显示时间
- 复制成功后按钮文字变「已复制 ✓」，1.5 秒后恢复

这些加起来不到 20 行 CSS，但页面会"活"起来。

---

## 建议的推进顺序

1. **先改作品屏为双栏** —— 收益最大，解决"字太多挤在小卡里"的老问题
2. **再改实习屏为轴 + 详情** —— 解决"实习经历不够突出"（你提过至少三次）
3. **最后加微交互** —— hover 反馈、点击复制、渐进展开

配色完全不用动，我们只改结构和交互。

# 个人作品集 · Portfolio

徐皓萱 / Hazel Xu 的综合作品集，收录内容传播、互动体验和影像创作。

**[打开正式网站 →](https://xu-125.github.io/portfolio/)**

## 可以看什么

- **互动体验**：Odyssey · 人生坐标。
- **影像创作**：AI 短片与独立拍摄广告，完整成片在影像画廊中。
- **内容与营销**：产品传播、活动内容与新闻报道，项目卡片提供作品原文入口。
- **毕业设计**：乡村小学交互式长报道。

网站中分别标注个人独立作品与参与项目；具体参与以各作品说明为准。

## 仓库结构

- `index.html`：网站内容、样式与交互。
- `img/`：现有图片、视频和作品封面。

这是静态展示网站，不包含用户系统或后台服务。页面可通过 GitHub Pages 浏览，也可在本地启动静态服务预览。作品素材用于展示，不因代码公开而自动获得转载或商用授权。

## 维护

更新作品时同步修改页面里的卡片、作品入口、封面和画廊信息，并检查桌面与手机显示。联系方式在正式网站中维护，避免在多个仓库重复保存。
